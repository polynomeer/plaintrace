## Observed minimum-interpreter failures and repairs

The first Python 3.10.22/macOS run discovered 486 tests with zero skips but seven failures and 29 errors; installed-browser smoke also failed. SQLite URI interpretation and EVTX fractional-time parsing were the causes. After fixing those code paths, targeted browser/EVTX tests passed on Python 3.10; new regressions preserve read-only snapshots and exact raw XML times. Final full runs below include all later gate tests. Failure logs stay outside Git; this summary retains the negative finding rather than overwriting its history.

All final runs used python-evtx 0.8.1 and hexdump 3.3. The direct unittest discovery command also passed all 489 cases on macOS/Python 3.14.8. Gate tests reject skips/expected failures as qualification even when ordinary unittest calls them successful. Source/test/tool digests match across all three environments. No unintended test-input mutations, failure waivers or host-specific skips were used to obtain green results.

The same pure-Python wheel, generated by setuptools 84.2.1, was installed into each environment. Installed module bytes were compared to that wheel. The smoke verified console and isolated-module entry points, synthetic Unicode/time interpretation, schema 15 JSON/SQLite parity, source preservation, foreign keys and no-overwrite behavior. It does not certify every installed artifact adapter; those adapters are exercised by the full source suite.

Linux ran in an ephemeral Docker container with network disabled, read-only root/source/wheelhouse mounts, a writable temporary filesystem and a separate results mount. CPU/memory/PID limits were applied. The container was removed after the run. This qualifies only the recorded container tuple, not Ubuntu/x86-64, native Linux hosts or Windows behavior.
