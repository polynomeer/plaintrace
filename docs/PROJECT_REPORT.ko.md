# 프로젝트 결과 보고서와 산출물 현황

[English](PROJECT_REPORT.md) | **한국어**

2026-10-13 보존된 소스를 기준으로 작성한 사후 문서입니다. 2017년 당시의 원본 산출물이 아닙니다.

## 당시 프로젝트

학부 BoB 디지털포렌식 프로젝트 기간인 2017년 7–11월 개발한 PVMA입니다. 현존 소스는 12개 Windows 아티팩트 모듈의 다중 탭 EnCase 플러그인을 구성합니다. 기존 README에는 UI와 EnScript 추출·파싱 개발이 설명되어 있습니다. 에이콘 출판사 집필 계약·그랑프리 도전 자격·더존비즈온 초청 발표도 기록되지만 계약서·발표 자료·평가 원본은 저장소에 없습니다.

## 현재 아카이브 작업

master의 기존 5개 커밋 대신 재구성 사실을 명시한 263개 기록용 커밋을 2017년 7–11월 날짜로 배치했습니다. 마지막 아카이브 tree는 이전 최종 tree와 일치합니다. 원본은 로컬 백업 ref·검증한 bundle에 남겼습니다. 후속 도구·문서는 실제 날짜로 기록하며 작성자 요청으로 원격에 반영했습니다. 범위는 [히스토리](HISTORY.ko.md), 문서 세트는 [목차](README.ko.md)를 참조하세요.

## 검증 근거

재구성 작업 공간에서 현 EnScript 13개 해시·과거 README 해시·263개 날짜/부모/변경 파일·원본 tree 검사를 통과했습니다. 문서 작업은 상대 링크·언어 쌍·소스 인덱스 위치·SQL 참조를 확인합니다. EnCase 컴파일·파싱 정답 대조·브라우저 렌더링·성능·포렌식 신뢰성은 미실행 또는 blocked입니다. 과거 테스트 통과나 릴리스 인증을 주장하지 않습니다.

## 인수인계

요구사항→아키텍처→구현 참조→데이터 출력→인수 계획으로 탐색할 수 있습니다. 전체 기준 검증에는 원본 백업, 런타임 작업에는 기록된 EnCase 환경이 필요합니다. 지원 확장·시각화 수정 전에 환경과 fixture를 마련하는 것이 우선입니다. 미해결 문제와 제안 순서는 [유지보수](MAINTENANCE.ko.md)에 있습니다.
