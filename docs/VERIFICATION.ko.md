# 문서 산출물 검증 보고서

[English](VERIFICATION.md) | **한국어**

2026-10-13 보존된 소스를 기준으로 작성한 사후 문서입니다. 2017년 당시의 원본 산출물이 아닙니다.

## 범위

보고일: 2026-10-13. 보존 구현의 사후 문서 작업을 검증합니다. 변경은 문서와 문서 검증 도구에 한정하며 EnScript는 수정하지 않습니다. 아래 검사는 저장소 일관성이며 런타임 정확성을 입증하지 않습니다.

## 수행한 검사

| 검사 | 방법 | 결과 |
| --- | --- | --- |
| 원본 소스·히스토리 | 원래 작업 공간의 python3 tools/verify_archive.py | 통과: 소스 13개·과거 README·263개 커밋·기준 tree |
| 소스 참조 생성 | python3 tools/generate_source_reference.py --check | 통과: 두 언어 참조가 소스 추출과 일치 |
| 소스 행 인용 | 대상 디코딩·클래스/메서드/SQL 위치 대조 | 명시한 제한 범위에서 통과 |
| 상대 문서 링크 | Markdown별 경로·파일/행 앵커 해석 | 저장소 내부 대상 통과 |
| 언어 쌍 | 영문·국문 존재와 전환 링크 | 모든 문서 주제 통과 |

| 공백 | git diff --check | 통과 |

## 수행하지 않은 검사

EnCase 컴파일·실행, 증거 파싱 정답 대조, GUI 조작, DB 내보내기 왕복, 웹 타임라인 렌더링, 버전별 호환성, 성능 측정은 수행하지 않았습니다. HTML 런타임 항목은 자산 누락으로 blocked입니다. 당시 원본 설계·테스트 기록은 제공되지 않았습니다.

## 재현 명령

```sh
python3 tools/inspect_sources.py
python3 tools/generate_source_reference.py --check
python3 tools/verify_documentation.py
python3 tools/verify_archive.py
git diff --check
```

전체 아카이브 검증에는 원래 로컬 백업 ref가 필요합니다. [설정](USER_GUIDE.ko.md)을 참조하세요. 런타임 인수 항목·결과 양식은 [검증 계획](TEST_PLAN.ko.md)에 있습니다. SQL 부록은 선언 목록이며 실행을 통과한 마이그레이션이 아닙니다.

## 전체 소스 및 번역 검토

진입점, 포함된 모듈 12개, 활성 SQL과 내보내기 핸들러를 두 언어 문서와 대조했습니다. 주석 처리된 코드와 실제 구현을 구분했습니다. 보존된 소스를 수정하지 않고 다음 문서 내용을 바로잡았습니다.

| 발견 사항 | 수정한 설명 |
| --- | --- |
| DB 경로 | WindowsArtifact.sqlite는 주석에 등장하며 활성 기본값은 WindowsArtifacts.sqlite와 두 타임라인 출력 경로 사용 |
| Recent Documents | 뷰어 출력은 CSV이며 뷰어 SQL 정의는 주석 처리; App_Documents는 활성 상태 |
| 차트 | 시스템 차트는 선택 항목을 확인하고 Prefetch/웹 차트는 SQLite 조회 |
| 전체 타임라인 | 초기 테이블 선언 9개에 Web_Visit/Web_Host가 없으며 브라우저 삽입은 성공이 검증된 통합이 아닌 시도 |
| 브라우저 검색어 | CSV 변환 후 리더 재사용은 소스 수준의 위험 |
| 미완성 컨트롤 및 헬퍼 | Recent SQLite 처리와 종료 시각 변환은 미완성 |
| USB 내보내기 | 레지스트리/이벤트 기능이 다르고 이벤트 헤더가 출력 필드를 올바르게 설명하지 않음 |
| 번역 | 런타임 경로 표기, 기술 리터럴과 설명 동기화 |

테스트 계획에 차트 및 추출 회귀 사례와 발견 사항별 검증 항목을 추가했습니다. 자동 번역 검사는 구조 외에도 인라인 기술 리터럴과 언어별 문서 링크를 비교합니다. 이는 문장 의미의 일치나 실행 성공을 입증하지 않으며, 각각 수동 검토와 호스트 검증이 필요합니다.
