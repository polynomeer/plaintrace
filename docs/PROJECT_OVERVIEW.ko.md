## 프로젝트 정체성과 목적

Plain View of Multi Artifacts(PVMA)는 현재 `plaintrace`에 보존된 EnCase EnScript 플러그인입니다. 여러 포렌식 아티팩트를 통해 Windows 사용자 행위를 살펴봅니다. 작성자 설명에 따르면 학부 재학 중 BoB 디지털포렌식 프로젝트로 2017년 7–11월 개발했습니다. 아티팩트 조회·추출·표 확인·데이터베이스 생성을 하나의 호스트 인터페이스에 모았습니다.

## 이해관계자와 범위

| 이해관계자 | 필요 사항 |
| --- | --- |
| 분석자 | EnCase 케이스의 Windows 아티팩트 조회와 결과 내보내기 |
| 검토자 | 표시 값에서 원본 파서까지 추적하고 제약 평가 |
| 유지보수자 | 레거시 구현 보존과 의존성 이해 |
| 프로젝트 열람자 | 2017년 개발 배경과 재구성 아카이브 이해 |

현존 구현 범위는 시스템 정보, 파일 메타데이터, 계정, 삭제 파일, Prefetch, LNK, 최근 문서, 로그인/전원 이벤트, USB, 브라우저 아티팩트, 타임라인 DB 생성입니다. 독립 포렌식 제품, 증거 획득 엔진, 모바일·클라우드 분석, 누락된 웹 시각화 전체는 현존 구현 범위 밖입니다.

## 출처와 근거

| 내용 | 근거와 해석 |
| --- | --- |
| 원래 이름과 BoB 기간 | 작성자 설명이며 합성 커밋 날짜에서 추론하지 않음 |

12월 도움말 표기는 모든 변경의 실제 시점을 입증하지 않으며, 작성자가 설명한 7–11월 프로젝트 기간을 대체하지 않습니다. EnCase 버전, 당시 배포 패키지, 원본 설계도, 테스트 결과, 개인별 작업 배분은 확인되지 않았습니다.
