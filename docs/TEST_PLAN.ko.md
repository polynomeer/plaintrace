# 검증·테스트 계획

[English](TEST_PLAN.md) | **한국어**

2026-10-13 보존된 소스를 기준으로 작성한 사후 문서입니다. 2017년 당시의 원본 산출물이 아닙니다.

## 상태와 전략

macOS에서 아카이브 무결성·문서 링크를 확인할 수 있습니다. EnCase 컴파일, 파서 정확성, 전체 UI 동작·성능은 미검증입니다. 아래는 제안된 실행 계획이며 과거 테스트 통과 기록이 아닙니다. 독립적으로 기대값을 확인한 합성 또는 사용 권한이 있는 증거를 사용합니다.

## 실행 결과 양식

테스트 ID·소스 커밋·Windows/EnCase 버전·fixture 해시·독립 기대값·선택 범위·출력 해시/행 수·실제 값·진단·결과(pass/fail/blocked/not run)를 기록합니다. 실패 재현 절차를 추가합니다. 진행 표시 완료만으로 통과 처리하지 않습니다.

## 향후 릴리스 종료 기준

호스트 컴파일과 지원 포맷 fixture 통과, 내보내기 값 보존, 시각 해석 문서화, 범위·반복 실행 명시가 필요합니다. 알려진 실패는 수정하거나 제외를 명시해야 합니다. HTML 항목은 자산·계약 복원 전 blocked입니다. 성능은 증거 크기·항목 수·시간·출력 크기·자원 사용을 기록하며 과거 목표가 없어 목표 충족을 주장할 수 없습니다.

[요구사항](REQUIREMENTS.ko.md), [분석](ANALYSIS.ko.md), [사용 가이드](USER_GUIDE.ko.md)를 참조하세요.
