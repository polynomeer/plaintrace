# Python CLI 코드 리뷰

[English](PYTHON_REVIEW.md) | **한국어**

## 범위와 보존

2026-10-14 codex/python-browser-cli에서 모든 Python 모듈, 패키징, 실행 가능한 픽스처와 영문·국문 문서를 검토했습니다. 수동 코드 리뷰와 합성 증거 기반 실행 검사이며 독립 리뷰어나 실제 획득 프로필 인증을 주장하지 않습니다. EnScript는 bb476180453c76f7d38e5b6a9f1f025ad2273ce0과 바이트가 같습니다. 원본 아카이브 태그, 매니페스트와 2017년 합성 커밋 263개는 유지합니다.

## 발견 사항과 수정

| 우선순위 | 발견 사항 | 수정 |
| --- | --- | --- |
| 높음 | 전체 쿼리 디코딩이 검색과 무관한 잘못된 UTF-8 필드에서 실패하여 정상 검색어 누락 | 검색 필드를 독립 디코딩하고 잘못된 필드를 진단하며 정상 인접 검색어 유지 |
| 높음 | 최종 출력의 dangling symlink을 해석하여 대상 위치에 조용히 기록 | 상위 경로만 해석하고 기존 최종 심볼릭 링크 거부 |
| 높음 | 새 출력 DB가 오래된 SQLite 사이드카와 함께 게시될 수 있음 | 직렬화 전과 게시 전에 기존 출력 WAL/SHM/저널 거부 |
| 중간 | ISO 시간대 변환이 범위를 초과하여 명시한 실패 처리에서 벗어남 | 원시 값을 유지하며 invalid_timestamp 진단으로 변환 |
| 중간 | 지원하지 않는 값의 직렬화 실패로 stdout에 부분 JSON 객체가 남음 | 엄격한 JSON 직렬화를 완료한 뒤 stdout에 쓰고 비유한 JSON 값 거부 |
| 중간 | 브라우저 테이블 이름이 뷰를 가리켜 네이티브 행 출처 추론이 잘못될 수 있음 | 지원 네이티브 테이블로 표시된 뷰 거부 |
| 중간 | Firefox 다운로드 요약에 선택한 주석과 이벤트 ID 누락 | annotation_ids와 start_visit_id를 출력하고 JSON/SQLite 출처 검증 |
| 중간 | 대응 URL 없는 저장 검색어와 역전된 다운로드 시각이 진단되지 않음 | 값을 보존하고 전용 진단 생성 |
| 낮음 | 프로그램 API에서 미지원 출력 형식을 조용히 JSON으로 선택 | 미지원 형식을 명시적으로 거부 |

## 남은 한계

다양한 브라우저 버전의 실제 획득 프로필, Windows/Linux, 최소 Python 버전 실행, 큰 자료와 전원 손실 동작은 이 환경에서 미검증입니다. 출력 파일시스템은 하드 링크를 지원해야 하며 사이드카 검사는 모든 관련 경로의 원자적 예약이 아닙니다. 해시 안정성이 라이브 획득을 원자적으로 만들거나 입력 WAL과 DB의 대응 관계를 입증하지는 않습니다. 결과와 직렬화한 stdout은 메모리에 유지합니다. 출력 스트림 중단은 전달된 stdout을 부분 상태로 남길 수 있습니다. 잘못된 미지원 행 타입은 복구 대신 명령 실패로 처리할 수 있습니다. 삭제 행 카빙, 미커밋 트랜잭션 복구, 암호화 DB, 증거 이미지 추출, 나머지 비브라우저 모듈/IE 아티팩트는 구현하지 않습니다.

EnCase 컴파일/실행은 미검증이며 Python 테스트로 입증하지 않습니다. 사용자가 로컬 검사 후 일반 병합을 통한 최종 통합을 승인했습니다. 병합은 실제 프로필, Windows/Linux 또는 EnCase 검증을 입증하지 않으며 EnScript, 아카이브 태그나 과거 커밋을 재작성하지 않습니다.

이 기록은 PR #2의 브라우저 이식 리뷰를 설명합니다. 현재 LNK/Prefetch 확장과 버전 2 계약은 [실행 사용법](EXECUTION_CLI.ko.md)에 정리합니다.
