# 멀티 OS 확장 기획

[English](CROSS_PLATFORM_PLAN.md) | **한국어**

2026-10-27 · 향후 확장 설계. 구현·호환 인증 결과가 아닙니다. 현재 패키지 0.15.0 / 보고서 스키마 15는 변경하지 않습니다.

## 목표와 현재 기반

Plaintrace를 분석자 PC와 독립적으로 Windows·macOS·Linux 증거를 해석하는 오프라인 도구로 확장합니다. EnScript 아카이브는 별도의 역사적 제품으로 보존합니다. 현재 Python 구현은 브라우저 SQLite, LNK/Prefetch, EVTX, 휴지통 및 SAM까지의 제한된 레지스트리 아티팩트를 처리합니다. macOS/Linux 고유 아티팩트 파서는 아직 없습니다.

저장소는 Python 3.10+를 선언하며 최근 전체 검증 기록은 2026-10-26 macOS/Python 3.14에서 EVTX extra를 포함한 475개 테스트입니다. Windows/Linux 실행이나 모든 포맷 버전 지원을 입증하지 않습니다. [현재 계약](SAM_ACCOUNTS_CLI.ko.md)과 [검증 기록](SAM_ACCOUNTS_TESTS.ko.md)을 참조하세요.

## 사용자와 핵심 흐름

주 사용자는 이미 획득된 자료를 다루는 포렌식 분석자와 사고 대응자입니다. 명시적 획득 파일 또는 매니페스트 등록 → 해시·동반 파일 확인 → 포맷 지원 탐지 → 실행 전 계획 확인 → 자원 제한 파싱 → 원시 관측·진단 검토 → 출처를 포함한 JSON/SQLite 내보내기를 제공합니다. 향후 시각화 계층은 같은 파서 결과를 사용합니다.

현대 Linux 분석 PC에서 획득 Windows 하이브를, 현대 Windows 분석 PC에서 획득 macOS plist를 해석할 수 있어야 합니다. 호스트에서 직접 수집하는 기능을 추가한다면 별도 제품 범위와 획득 검증이 필요합니다.

## 요구사항과 인수 기준

| ID | 요구사항 | 인수 근거 |
| --- | --- | --- |
| CP-01 | 실행 호스트·증거 OS·포맷 리비전 분리 | 동일 획득 fixture가 3개 호스트 계열에서 동등한 관측 생성 |
| CP-02 | 입력과 출처 계보 보존 | 전후 해시, 쓰기 거부 검사, 원본 오프셋·획득 매니페스트 유지 |
| CP-03 | 확인된 레이아웃만 해석 | 알 수 없는 리비전은 미지원 또는 명시적 부분 지원, 묵시적 대체 금지 |
| CP-04 | 모든 파서·보고서 자원 제한 | 제한·타임아웃 테스트에서 통제된 진단, 부분 결과 발행 없음 |
| CP-05 | 원천 의미 보존 | 원시 시간·경로·중복 필드 왕복 및 독립 기대값 검증 |
| CP-06 | 호환성 근거 공개 | 릴리스 지원 항목에 정확한 환경·fixture 결과 연결 |
| CP-07 | 기존 보고서 재현성 유지 | 스키마 15 회귀와 선택적 차기 스키마 변환 비교 |
| CP-08 | 아카이브 보존 | 역사적 blob/ref 검사 및 EnScript·매니페스트 무변경 |

## 범위와 우선순위

P0: 호스트 호환, 입력 매니페스트·출처 계약, 지원 등록부를 먼저 완성합니다. P1: 제한된 macOS plist·시스템 메타데이터와 Linux os-release·계정 메타데이터, 공통 브라우저 검증을 추가합니다. P2: Linux journal export와 선별 macOS 앱 DB를 버전별로 이식합니다. P3: 구형 포맷, 파일시스템 메타데이터, 선택적 읽기 전용 보고서 UI를 확장합니다.

원시 디스크 이미지·파일시스템 드라이버, 암호화 볼륨, 삭제 복구, 라이브 에이전트, 원격 수집, 자동 신원 결합, native unified log/Spotlight/FSEvents 해석은 별도 결정 후 진행합니다. 자격 증명 복호화·대상 실행·보고서 기반 네트워크 접근은 범위 밖입니다. 아티팩트 부재는 자료 이용 불가이며 행위 부재의 근거가 아닙니다.

## 산출물과 주요 결정

EnScript 재작성이나 서비스 도입 대신 기존 Python 코어를 확장합니다. 호스트 자동 검색보다 명시적 오프라인 파일을 먼저 지원합니다. OS 제품명보다 검증된 포맷 기능을 기준으로 호환성을 결정합니다. 관측을 우선 보존하고 파생 해석에는 규칙과 출처를 연결합니다.

[호환성 정책](CROSS_PLATFORM_COMPATIBILITY.ko.md), [아키텍처·계약](CROSS_PLATFORM_ARCHITECTURE.ko.md), [구현·검증 로드맵](CROSS_PLATFORM_ROADMAP.ko.md)을 함께 읽으세요. 이번 산출물은 설계 문서이며 구현·CI 실행·패키징·증거 획득은 후속 작업입니다.
